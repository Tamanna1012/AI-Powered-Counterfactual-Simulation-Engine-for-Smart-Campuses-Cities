# CS4-S01 Complete Team Project (master archive)

BCSE412L Parallel Computing - VIT Vellore - Case study CS4-S01: Parallel Breadth-First Search.

| Folder | Owner | Main contribution |
|---|---|---|
| `Lucky_Sequential_BFS/` | Student 1 | Sequential BFS baseline, graph preparation, correctness validation, baseline timing |
| `Girlfriend_OpenMP_Parallel_BFS/` | Student 2 | OpenMP parallel BFS, thread scaling, synchronization/overhead, speedup/efficiency/TEPS |
| `Word_Documents/` | both | The one integrated report + both individual technical notes (the same files that are inside the two folders) |

Each folder is a complete, self-contained copy of the shared project (code, tests, raw/derived CSV, figures, scripts) so either one can be built, tested and re-analysed alone. The two folders differ only in `CONTRIBUTION.md`, `PACKAGE_NOTES.md` and the individual technical note. Start with each folder's `CONTRIBUTION.md`, `PACKAGE_NOTES.md` and `README.md`.
`SHA256SUMS.txt` lists a checksum of every Word document and the raw/derived CSV, so you can see that the shared files are identical everywhere.
